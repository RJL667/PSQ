# Standard conditions of cover: general template (underwriter, 29.10.2026)

Use this exact wording for conditions of cover on quote instructions. Include only the conditions the form does not show as met,
plus any confirmation notes (see underwriting_nuances.md for per-condition rules).

- The controls and procedures filled out in the submitted assessment form, are at a minimum the level of all listed entities.
- Sophos MDR Essentials/Complete deployed on all access devices and entire network, with endpoints deployed/not deployed, or comparative Managed, Detection and Response program in place; if so, please specify.
- Data backups are done at least weekly, and a separate set should be immutable or isolated from production.
- Password complexity and reuse policies are in place for all logins.
- Critical systems are hosted in access-controlled areas.
- Critical systems are backed up offsite.
- Endpoint Detection & Response (EDR) or ETDR tools are deployed on all access devices.
- Ensure a Two-Way Traditional Firewall is active, and sufficiently configured for the business' specific needs on the network.
- An e-mail filtering solution that blocks malicious attachments and suspicious file types, including executables.
- A web-filtering solution that blocks known malicious or suspicious downloads, including executables.
- A cyber threat intelligence capability.
- A defined process for remediating vulnerabilities.
- High-risk protocols (e.g. RDP, SMBv1) should be disabled externally.
- An incident response plan that is tested, at least annually, with executive participation.
- Multifactor Authentication (MFA) is implemented for all privileged accounts.
- MFA and VPN implemented for all remote logins into network.
- Formal security awareness training is provided to all employees, at least annually.
- Phishing simulations are conducted regularly to all employees.
- Fraud payment controls for Funds Protect Authorised Losses.

Note: underwriting_nuances.md (cyber threat intelligence section) says not to impose the CTI condition while the scanner
provides threat intelligence. The template still lists it; the per-case rule decides whether it goes on a quote.
